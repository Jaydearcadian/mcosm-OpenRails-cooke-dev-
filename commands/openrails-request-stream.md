# openrails request-stream

Build a RailsFlow request link.

```bash
openrails request-stream --chain-id <id> --hub <address> --token <address> --metadata-hash <bytes32> --merchant <address> --recipient <address> --amount <base-units> --flow-velocity-per-second <base-units-per-second> --lifespan-seconds <seconds>
```

This command is read-only. It returns an unsigned request link and cannot move funds.
