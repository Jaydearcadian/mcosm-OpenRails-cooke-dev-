# OpenRails product surfaces

OpenRails is one system expressed through several surfaces.

- **Narrative** explains the original programmable settlement thesis and the Runtime that now surrounds it.
- **System Lab** is the public proof environment. It is not the future dashboard.
- **Network** verifies canonical state and deployment evidence.
- **Build** gives developers an architectural entry point.
- **Docs** explains every primitive, boundary, lifecycle, and integration.
- **Personal dashboard** will eventually operate the entire system around one account, Workspace, organisation, or agent estate.
- **Telegram, MCP, SDK, and APIs** are clients and sidecars, not the product itself.

The canonical product hierarchy is:

1. OpenRails Protocol — RailsCard, RailsFlow, Paycard, Vault, nonce lanes, velocity gates, STN-Delta, receipts.
2. OpenRails Runtime — Workspace, actors, Path, proposal, Baphomet, Pact, Proof, Gaia.
3. OpenRails Clients — System Lab, dashboard, Telegram, SDK, MCP, REST and application integrations.
